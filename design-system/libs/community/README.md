# libs/community — Community-contributed components

This library holds all components submitted by community contributors via the Design System Portal.

## Adding a component

Use the [Portal UI](http://localhost:4200/submit) or follow [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Structure

Each component lives in its own directory:

```
src/lib/
├── fancy-card/
│   ├── fancy-card.component.ts
│   ├── fancy-card.component.html
│   ├── fancy-card.component.scss
│   ├── fancy-card.component.spec.ts
│   ├── fancy-card.stories.ts
│   ├── index.ts
│   └── README.md
└── ...
```
